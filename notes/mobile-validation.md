# 移动端验收

## 存储授权

- 启动、登录和试听不申请文件权限。下载默认使用应用目录。
- 选择下载/同步目录时，仅通过系统文件夹选择器申请该目录的读写授权，持久保留 URI；不申请“所有文件访问”或音频库读取权限。
- Android 10 及以下访问历史保存的普通外部路径时，按需申请传统读写权限；这不保证对外置 SD 卡的普通路径可写。遇到旧路径权限错误应重新选择文件夹，改用系统目录授权。
- 选择时实际写入并删除一个临时探测文件；读取失败不当成空目录，避免误判需要下载全部歌曲。
- 下载、标签处理先在应用缓存内完成，再通过授权流导出；本地跨目录拷贝、歌词写入、同步删除也使用授权流。
- 拔卡、目录授权被撤销时显示错误，不自动切换存储位置。

真机检查 Android 10 内置存储、外置 SD 卡；Android 11+ 可选目录；重启应用后授权是否保留；拒绝/取消选择；撤销授权和拔卡。验证音频、LRC、已有文件复制及多余文件删除。外置 SD 卡上仅授予传统读写权限不能替代系统目录授权。

## VIP 下载保护

- 检查落盘音频实际长度；仅 VIP 歌曲约 20/30 秒、且明显短于原曲时触发。歌曲本身很短不误拦截。
- 当前和新增 VIP 自动暂停；普通歌曲正常下载。下载顶部显示简短提示及“重试这首歌”。
- 单首“继续”可强制放行该任务；“全部继续”及重复添加不绕过保护。
- 重试原触发曲目。仍为试听、下载失败或实际时长无法确认时，不解除保护；恢复完整长度后，仅继续因保护暂停的任务。
- 用户手动暂停的歌曲不自动继续。已识别的试听片段显示“仅试听片段”，不向同步的其他目录分发。

## 登录布局

检查 320px 宽度与放大字体：“选择文件”“粘贴剪贴板”“导入登录”自动换行，可见且可操作。

## 本次验证结果（2026-11-20）

- Android 10 / API 29 / KIW-TL00H，存在外置 SD 卡。
- 用户人工确认：登录键盘溢出已解决；授权目录写入已解决；预览恢复正常。
- Android Debug 构建成功，测试包已覆盖安装，保留登录数据。
- 自动化覆盖：320px 窄屏及键盘遮挡；VIP 20/30 秒检测、当前及新增 VIP 暂停、普通歌曲继续、单曲手动放行、重试仍为试听或未知时长不放行、完整重试恢复、取消后重试、快速暂停继续。
- VIP 试听保护使用可控下载/时长模拟验证；没有人为修改真实账号权益来触发。
- 测试期间未调整设备音量。

预览修复：网易云音频 HTTP 链接改用 HTTPS；Android 使用应用网络栈获取临时音频再播放，不请求媒体库权限；缓存换歌/关闭时清理，失败显示“试听失败，点播放重试”。首次播放会先缓冲此曲目。
